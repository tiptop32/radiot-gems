# Радио-Т: Находки

Курируемый каталог полезных тем из архива подкаста «Радио-Т». Каждая находка содержит категорию, уровень сложности, ссылку на официальный выпуск и точный таймкод.

## Как запустить

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
npm run eval
npm run lint
npm run build
```

## Данные

Стартовая выборка находится в `data/finds.json`. Для каждой темы хранятся:

- номер выпуска и каноническая страница на `radio-t.com`;
- официальный MP3 на `cdn.radio-t.com`;
- текстовый таймкод и его значение в секундах;
- категория, уровень и короткое объяснение ценности темы.

Страница выпуска «Радио-Т» не поддерживает запуск по таймкоду через URL. Поэтому основная кнопка использует встроенный плеер и устанавливает `currentTime`. Официальный таймкод остаётся источником данных, но воспроизведение начинается на 180 секунд раньше, чтобы не пропустить вводную часть разговора. Для тем в первые три минуты выпуск начинается с `00:00:00`.

Ссылка «MP3 за 3 минуты до темы» использует стандартный media fragment `#t=SECONDS` как запасной вариант. Его поддержка зависит от браузера.

Источник структуры данных: [официальный API Радио-Т](https://radio-t.com/api-docs/).
